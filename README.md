## ✅ 本版新特性

1. **应用宠物**：直接使用你提供的透明 PNG 素材（`renderer/assets/pet/pet-01..12.png`），不另做形象；沿窗口四边缓慢走动、可拖到任意位置；基础形象按时间切换（启动 01/02、21 点后 03、12:00 与 18:55 用 04、其余时间在 05–12 缓慢轮换），任务/完成/点击切对应素材并提示。
2. **右下角日历**：点 📅 展开，任意一天可添加“当天工作内容”（可填时间），当天待办由宠物气泡+弹窗提醒。
3. **资产拆分改进**：
   - 跨集**同名自动合并**（如“李青（镇北王世子）”与“李青”合并，不再重复）；
   - **自然环境物不拆分**（水、草丛、石头、树、泥土、灰尘、火焰、烟雾、光、风、雨、雪、云、天空、地面、河、海、月光、阳光等不进道具）；
   - 默认 **“全部资产（跨集汇总）”总览**，每项标注出现集数；可「📑 按集查看（查看补缺）」；
   - **「■ 停止拆分」立即清零进度**，切走切回也不重现旧进度；新增资产搜索框。
   - **断点续跑 + 并发提速**：只拆未完成的集数，中断后再点继续；同时处理 2 集。
   - **标签式查看**：单人 / 群像 / 场景 / 道具点击标签依次查看，集数网格可折叠。
   - **主要角色自动标注**：拆分后对“单人”资产按出场次数从高到低排序，前 8 名标注“主要角色 + 出场X次 + 角色词”。
4. **提示词生成**：每个资产卡片有自己的**“该资产的参考词（风格/细节/参考角色等）”**独立配置，生成时与全局前缀词一起使用，不再是总体配置。
5. 右侧只保留参数面板（已去除“当前内容编辑”），模型预设含 DeepSeek、豆包、千问、Kimi、GLM、自定义。

已通过 30 项自动化自测（宠物、日历、资产四板块/合并、停止重置、搜索、分镜网格、本地模拟 AI 流式调用等），打包后便携版再次自测通过。

## 🔧 运行前
首次使用在右侧「参数面板 → AI 模型设置」选择服务商并填入 API Key（本地保存），点「测试连接」。
